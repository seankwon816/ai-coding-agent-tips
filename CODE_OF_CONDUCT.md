# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in this repository a welcoming, respectful, and harassment-free experience for everyone, regardless of experience level, background, or tooling preference.

## Expected Behavior

- Focus feedback on technical accuracy, verifiable sources, and reproducible fixes.
- Cite official documentation, release notes, or published studies when challenging or proposing a tip.
- Be concise, constructive, and respectful in Issues, Pull Requests, and Discussions.

## Unacceptable Behavior

- Harassment, personal attacks, trolling, or discriminatory remarks.
- Spam, unrelated self-promotion, or unverified marketing claims.
- Publishing private credentials, API keys, or sensitive user data.

## Enforcement

Maintainers may edit, close, or remove contributions that violate this Code of Conduct. Report issues by opening a private security advisory or contacting the repository maintainer through GitHub.
