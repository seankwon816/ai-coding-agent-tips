# Contributing

Tips are welcome. To keep every tip trustworthy:

1. One problem and one fix per file in `tips/`, using `tips/_TEMPLATE.md`.
2. Name the tool version you checked it on.
3. Link the official doc or changelog line that backs it. No numbers you cannot source.
4. No product or company plugs.

Not sure it fits? Open a "Suggest a tip" issue first.
